PortWaver en breve

Los datos esenciales del proyecto, sin convertir esta página en un segundo README.

ResumenEspecificacionesFicha rápida

Propósito

Terminal gráfica para comunicación, análisis y automatización de enlaces serie.

Tecnología

Python, pySerial, pywebview y una interfaz HTML/CSS/JavaScript local.

Plataforma

Orientada actualmente a Windows y preparada para empaquetarse mediante PyInstaller.

Datos

Ajustes JSON, perfiles .UserVSP y registros de recepción en archivos de texto.

Estado

Desarrollo público sin una GitHub Release ni instalador descargable en este momento.

Dependencias

pywebview >=6.2,<7 y pyserial >=3.5,<4.
