Especificaciones

Un recorrido por las superficies que ya están implementadas en el repositorio público.

ResumenEspecificacionesFicha rápida

01 / Arquitectura

Frontend web, núcleo Python

La interfaz HTML, CSS y JavaScript se ejecuta dentro de una ventana pywebview. Una API Python controla el puerto serie, los archivos y la ventana nativa.

02 / Enlace

Configuración completa

Puerto, velocidad, tamaño de palabra, paridad, stop bits y controles XON/XOFF, RTS/CTS o DSR/DTR.

03 / Terminal

RX y TX en tiempo real

Recepción asíncrona, UTF-8 o ASCII, finales NONE/LF/CR/CRLF, conversión de líneas y vista estructurada de objetos JSON.

04 / Módem

Señales visibles

Control directo de RTS y DTR, envío de BREAK y lectura en vivo de CTS, DSR, DCD y RI cuando el transporte lo permite.

05 / Reglas

Procesamiento configurable de la recepción

Las reglas comparan por prefijo, sufijo, inclusión, igualdad, palabra completa, conjuntos o expresión regular. Una coincidencia puede mostrar, ocultar, reemplazar, añadir texto o enviar una respuesta automática.

06 / Productividad

Comandos rápidos

Botones con nombre, texto, color y tecla del teclado numérico. Las teclas F1–F12 también pueden asignarse a acciones globales.

07 / Archivos

Secuencias y registros

Envío de archivos de texto línea a línea con retardo configurable y captura RX en archivos fechados con tiempo transcurrido.

08 / Perfiles

Configuraciones transportables

Los perfiles .UserVSP guardan la configuración y pueden cargarse o eliminarse desde la interfaz.

09 / Pruebas

Emulación sin hardware

El modo loopback permite validar envío, recepción, señales y finales de línea. Las pruebas cubren bloqueos de puerto, perfiles, logs y ventana.

10 / Distribución

Aún sin release pública

El repositorio contiene scripts de construcción y configuración de PyInstaller, pero actualmente no publica instaladores mediante GitHub Releases. Por ello la web enlaza al código y no presenta una descarga inexistente.
