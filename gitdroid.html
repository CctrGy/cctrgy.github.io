01 / Qué es

Una mini-store segura y eficiente.

Descarga un único catálogo estático, obtiene los APK desde GitHub Releases, verifica su integridad y firma digital y solicita su instalación.

La aplicación móvil no recorre repositorios ni consume la API de GitHub: descarga catalog.json, generado centralmente cada seis horas por GitHub Actions.

Ver en GitHub ↗
02 / Flujo técnico
GitHub ActionsGenera catálogo→catalog.jsonUna descarga→VerificaciónSHA-256 · firma→AndroidPackageInstaller

Para aparecer, un repositorio público necesita una Release con un asset llamado exactamente app.apk y un version.json válido. Antes de instalar se verifican URL, SHA-256, certificado, packageName y versionCode.
