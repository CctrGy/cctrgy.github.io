01 / Qué es

GitHub convertido en tienda.

GitDroidStore detecta repositorios Android que publican APK y los presenta en una experiencia sencilla.

Consulta metadatos y releases, identifica los assets APK disponibles y muestra la versión adecuada.

Ver en GitHub ↗
02 / Flujo técnico
GitHub APIRepositorios→ReleasesDetectar APK→DescargaVerificar asset→AndroidInstalador

La app localiza releases con APK, descarga el asset elegido y lo entrega al instalador seguro de Android. En lugar de activar un permiso global, el usuario autoriza específicamente a GitDroidStore como fuente cuando el sistema lo solicita.
