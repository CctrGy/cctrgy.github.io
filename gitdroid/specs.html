README interactivo

Publicación y confianza

Cómo GitDroidStore construye un catálogo estático y valida cada APK antes de solicitar su instalación.

ResumenEspecificacionesFicha rápida

1. Descubrimiento

GitHub Actions inspecciona repositorios públicos y genera un único catalog.json cada seis horas o bajo demanda.

2. Publicación

Una aplicación requiere una release estable, un asset llamado exactamente app.apk y un version.json válido.

3. Integridad

Se contrastan SHA-256, URL del asset, package name, version code y certificado del APK.

4. Instalación

PackageInstaller.Session entrega el APK a Android. El sistema conserva la confirmación del usuario y sus políticas.

Contrato mínimo

{
  "packageName": "com.example.app",
  "versionName": "1.2.0",
  "versionCode": 12,
  "certificateSha256": "…"
}

Documentación fuente

La referencia completa, incluidos iconos, firma y errores de validación, se mantiene en el README del repositorio.
