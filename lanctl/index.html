01 / El proyecto

Una LAN que puedes entender, documentar y administrar.

LANCTL reúne descubrimiento, inventario, cableado físico, racks, credenciales, monitorización y auditoría en una suite coordinada.

El orquestador y sus aplicaciones comparten configuración, identificadores y servicios transaccionales, mientras cada dominio conserva la propiedad de sus datos. Los resultados pueden exportarse como tabla, JSON, CSV, HTML, XML o YAML.

Capacidades reales

Una herramienta, varias capas.

Desde descubrir dispositivos hasta abrir sus protocolos de administración y conservar la evolución de cada red.

01

Descubrimiento

ICMP, ARP y WS-Discovery en el núcleo; mDNS y SSDP mediante complemento LCP.

02

Inventario

Identidad por MAC, IP histórica, alias, fabricante, grupos, descripción y estados CNF.

03

Diagnóstico

Ping, ARP activo, escaneo TCP e identificación de servicios basada en evidencias.

04

Administración

Acceso a SSH, TR-064, Telnet, HTTP(S), FTP, RDP, RTSP y SMB.

05

Proyectos VLF

Contenedores verificables con inventario SQLite, configuración, credenciales cifradas y auditoría.

06

Suite coordinada

Aplicaciones especializadas para inventario lógico, cableado, racks, credenciales, monitorización y orquestación.

Aplicaciones paralelas

Una suite, responsabilidades claras.

Pueden permanecer abiertas a la vez y comparten una misma raíz de datos, sin mezclar la propiedad de cada dominio.

Flujo de trabajo

De la detección al inventario.

Los perfiles permiten elegir entre velocidad y profundidad sin cambiar de herramienta.

01

Descubrir

lanip ephemeral --normal

Localiza equipos mediante ICMP, ARP y WS-Discovery sin modificar proyectos ni inventarios. Los plugins pueden añadir mDNS y SSDP.

02

Identificar

lanctl scan CAM1 --identify

Utiliza banners y sondas inocuas, registrando producto, confianza y evidencia.

03

Consultar

lanctl list --where "active and group=IOT"

Filtra de forma segura por IP, MAC, alias, fabricante, protocolo, grupo o estado.

04

Conectar

lanctl open NAS ssh --dry-run

Prepara el cliente adecuado y permite revisar el destino antes de abrirlo.

03 / Proyectos VLF 1.0

Una red completa en un contenedor verificable.

Un archivo .vlf conserva metadatos, identidad de LAN, VLAN, topología, inventario SQLite, configuración, credenciales cifradas y auditoría diaria.

  • Hashes SHA-256 de contenido y checksum general.
  • Verificación de estructura y de integridad SQLite.
  • Actualizaciones transaccionales con copia .vlf.bak.
  • Compatibilidad garantizada dentro de la serie LANCTL 0.3.x.
  • Protección frente a rutas absolutas, duplicados y archivos sobredimensionados.
lanctl project verify Oficina.vlf

04 / Complement Platform 1.0

Extensiones con alcance declarado.

Los paquetes .lcp pueden añadir plugins, temas, idiomas, automatización, análisis, seguridad, protocolos, scanners y exportadores.

  • Runtime isolated para extensiones declarativas.
  • Runtime trusted con activación explícita mediante --trust.
  • Permisos, dependencias, eventos y namespaces verificables.
  • Instalación transaccional; un paquete nunca se activa automáticamente.
  • Modo seguro para recuperar el arranque ante plugins defectuosos.
lanctl plugin enable ID --grant-all --trust

05 / Seguridad operacional

Control antes que automatización ciega.

LANCTL está diseñado para redes autorizadas. Las operaciones sensibles requieren confirmación y las credenciales se protegen mediante DPAPI, vinculadas al usuario de Windows.

DPAPILas credenciales no se almacenan en texto plano.
Dry runPermite validar destinos y planes antes de actuar.
AuditoríaSepara actividad operativa de cambios en el inventario.
VLFVerifica hashes, rutas internas, tamaño y bases SQLite.
Capa gestionada Cisco

Planificar, clasificar y confirmar.

El flujo separa parser, planificación, política de riesgo y adaptador. Actualmente solo está habilitado el adaptador simulado.

  1. READ_ONLY se ejecuta sin confirmación.
  2. CONFIG_CHANGE exige autorización explícita.
  3. DESTRUCTIVE_OR_DISRUPTIVE requiere confirmación.
  4. PERSIST_CONFIG nunca queda implícito en otro cambio.
run switch SW --dry-run port show NAS status

07 / Ejecutar el proyecto

Windows, Linux y Raspberry Pi OS.

Python 3.10+ permite ejecutarlo desde el código. Los binarios actuales incluyen CLI, consola y TUI; la GUI antigua basada en pywebview está congelada y no se distribuye. Las operaciones de red requieren autorización y privilegios suficientes.

PowerShell
git clone https://github.com/CctrGy/LANCTL.git
cd LANCTL
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -e .

lanctl --tui
lanip --tui
lanip ephemeral --normal
lanip -e --fast --range 192.168.1.0/24
lanwire list
