LANCTL en breve

Una referencia corta para entender el alcance del proyecto antes de entrar en la documentación avanzada.

ResumenDescargarEspecificacionesFicha rápida

Propósito

Descubrir, inventariar, cablear, monitorizar y administrar una LAN mediante aplicaciones coordinadas.

Plataformas

Windows 10/11, distribuciones Linux y Raspberry Pi OS de 64 bits.

Interfaces

GUI, CLI, consola persistente y TUI, con exportación a tabla, JSON, CSV, HTML, XML y YAML.

Aplicaciones

LANIP, LANWIRE, LANRACK, LANACCESS, LANMON y LANDEMO acompañan al orquestador LANCTL.

Datos y seguridad

VLF verificable, SQLite y JSON transaccional, auditoría, DPAPI y complementos LCP aislados o confiables.

Estado actual

La rama principal documenta 0.3.0-beta.21; GitHub Releases ofrece la última compilación publicada.
